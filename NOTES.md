# Notes

## Teaching preferences
- **Mission**: General knowledge — building durable software design intuition. No deadline.
- **Current level**: Can name 1-2 principles vaguely. Has read articles, can't teach or spot violations.
- **Style**: Mix of visual, reading, and hands-on. Each lesson = short explanation → diagram → code exercise → recall quiz.
- **Stack**: Node.js + TypeScript. All code examples in this stack.
- Keep lessons short — one tangible win each (one principle per lesson, except introduction).

## Environment
- macOS (darwin)
- TypeScript available in workspace (`fincheck/api` is a NestJS project)
- Verify `npx tsc --version` before writing demos that need compilation
